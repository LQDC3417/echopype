# Echoview GUI 模板整合与大规模 RAW 稳定性计划

## 目标

在当前 `codex/ui-optimization` 分支中，将 GUI 调整为 `echoview_data` 模板所示的科研声学分析工作台，同时保持后端数据处理、前端状态和 Echogram 显示一致。优先解决真实数据测试中已确认的稳定性和交互问题。

## 已确认的产品约束

- 右侧属性区采用单页纵向滚动分组，不使用多页签切换。
- 工作区进行完整重排，保留当前深色背景和青色强调色，尽量贴近模板。
- 显示参数即时应用；计算参数只重算当前功能，并将下游结果标记为过期，不自动级联重算。
- 每个功能的参数变更独立触发当前功能，取消依赖统一“应用全部”才能生效的流程。
- 处理开关在无数据时禁用；打开后立即显示已有或刚计算的结果，关闭只隐藏结果，不删除缓存。
- 多文件导入采用“成功文件继续、失败文件明确报告”的策略，不静默跳过。
- 底线检测针对合并后的完整数据集执行。
- 鼠标手爪模式通过工具栏/快捷工具进入，左键拖动 Echogram 完成平移；保留现有噪声选择、底线绘制和检查工具。
- UI 保持中英文双语能力，沿用现有 i18n 机制。

## 风险与控制

- 大规模 RAW 仍可能受磁盘、内存和 Echoview 数据格式影响；先用小批量和 8 文件样本验证，再扩大规模。
- 当前 worktree 已有其他会话的未提交变更；所有编辑均采用局部补丁，不执行 reset、checkout 或批量格式化。
- GUI 测试可能受 OpenGL/Qt offscreen 环境限制；将区分逻辑测试、组件测试和真实桌面烟测结果。
