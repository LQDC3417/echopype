# 仓库合理性复核

日期：2026-09-27。基线：`mimo_ui` 分支的 `a4d61f2`；本轮修复尚未提交。

## 结论

项目架构适合继续开发淡水鱼类声学调查工作台：RAW 经 echopype 校准，`merge_aligned` 拼接，分析结果与通道状态保存在 `.ep`，GUI 与快照 replay 共用处理链路。独立模块和测试较完整。复核仍发现会影响多通道数据、积分值、显示一致性和导出的真实错误；本轮已修复并加回归测试。当前可作为研发和限定范围的调查分析版本，不能仅凭内部测试宣称与 ESP3/Echoview 科学等价或已通过全量现场验收。

TypeSafe AI 技能所描述的 System One 用于有不确定性的语义判断。本项目的 Sv、ABC 和密度计算属于确定性数值过程，继续由现有算法和 echopype 完成；本轮没有引入 TypeSafe 运行时依赖。

## 本轮修复

| 范围 | 发现的错误 | 修正与回归 |
|---|---|---|
| 多通道 GUI | 第一次切换到未保存状态的通道会在 `None.get()` 处报错；旧通道网格和 SED 点残留 | 初始化缺失状态，切换通道清除旧叠加层；双通道 GUI 回归 |
| 声图与数据 | 恢复人工掩膜时 `Sv_corrected` 已更新，但声图仍显示原始 Sv | 绘制、导航缩略图与变量列表统一读取活动 Dataset；重开项目和通道切换回归 |
| SED | 选择通道后仍保留长度为 1 的 channel 维，后续二维计算失败 | 标量选择通道；双通道目标检测回归 |
| 分析区域 | 裁剪会把首通道数据误写入其他通道 | 按维度广播区域 mask，同时裁剪 `Sv` 与 `Sv_corrected`；多通道不污染输入回归 |
| 积分 | 全空 ping 参与 ABC 均值导致低估；末层上边界样本被漏计 | ABC 只平均有效 ping，末层包含最大深度；边界回归 |
| 导出 | 空结果 Excel 报错；GUI 的 Zarr 选项没有实际导出，缺少依赖声明 | 空表写说明页，接通 Zarr 并声明依赖；同名 Zarr 目录提示用户且保留原内容；Excel、Zarr 实际往返和 GUI 路径回归 |
| 安装元数据 | 包声明 Python 3.10+，但当前 echopype 0.11.1 要求 3.11–3.13；且未限制 echopype 次版本 | 将 Python 限为已验证的 3.11–3.13、echopype 限为 0.11.x，并对齐 README |
| 文档 | `AGENTS.md` 误称当前为深色主题；README 目录树和测试描述过时 | 对齐实际浅色主题、主要模块和测试入口 |

## 验证

- Anaconda Python 3.13.5、echopype 0.11.1；`ruff check src tests`、`compileall -q src tests`、`git diff --check` 均通过。
- 默认测试：318 passed，39 skipped。真实 RAW 测试：355 passed，1 skipped；随后新增的同名 Zarr GUI 测试单独通过，未重复运行耗时约 2 分钟的真实数据套件。真实测试包含仓库内 RAW；跳过项依赖未提供的额外数据目录。
- 构建 wheel 成功；安装包包含 GUI、replay、预设和 SVG 图标。Zarr 依赖已加入两份依赖清单。
- 自动化 GUI 用 Qt offscreen；它不能替代有显卡桌面的 OpenGL 交互验收。

## 仍需验收或决策

1. 用同一批 RAW、校准参数、线和阈值与 ESP3/Echoview 的导出结果逐格比对；目前没有外部基准结果，无法量化算法偏差。
2. 既有 2026-09-26 记录仅验证了连续 10 个 RAW、约 1.05 GB 的拼接与 replay；全目录约 31.29 GiB、335 个 RAW 尚未验收，不能据此承诺大规模稳定性。
3. 真实多通道、跨设备混合输入、长时间 OpenGL 缩放编辑和持续运行内存曲线仍需现场测试。
4. GUI 显示 `2.0`，而安装包版本是 `0.1.0`；申报或发布前应统一对外版本口径。用户指南另标 `2.1`，也需随申报版本更新。
5. 普通文件格式导出仍沿用同名文件覆盖行为；正式发布前需决定是否统一提示覆盖。软著申请主体、贡献权属及第三方组件资料也不能通过代码测试确认。
