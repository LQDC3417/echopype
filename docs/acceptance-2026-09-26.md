- `.ep` v1.3 保存通道状态和强类型结果表；历史旧 JSON 表中已丢失的精度无法恢复。
- GUI 和 replay 对积分使用相同的预处理步骤；replay 不回放操作历史，也不重新运行底部、鱼群或 SED 检测。
