# Echogram 功能测试说明书

**版本**: 2.0  
**更新日期**: 2026-08-08  
**测试数据**: `raw_data/20250706SCSK-D20250706-T024009.raw` (SCSK 水库，170MB)

---

## 一、环境准备

1. 启动 GUI：`python -m src.app`
2. 确认主窗口正常显示：左侧文件树、中央回波图、右侧属性面板

---

## 二、测试流程（共 12 步）

### 第 1 步：导入数据

| 操作 | 说明 |
|------|------|
| 菜单 | 文件 → 导入 Raw 文件（Ctrl+I） |
| 选择 | 选择 `raw_data/20250706SCSK-D20250706-T024009.raw` |
| 预期 | 文件树出现该文件，双击加载后中央回波图显示彩色回波 |

**检查点**：
- [ ] 文件成功加载
- [ ] 回波图正常显示
- [ ] 状态栏显示通道和 ping 数信息

---

### 第 2 步：查看 Sv 数据

| 操作 | 说明 |
|------|------|
| 检查 | 属性面板 → 文件信息标签页 |
| 检查 | 状态栏底部显示 ping 数、sample 数 |

**检查点**：
- [ ] 文件信息面板显示正确的通道、频率、ping 数
- [ ] 回波图颜色映射正常（Sv 范围 -80 ~ 10 dB）

---

### 第 3 步：设置表线深度

| 操作 | 说明 |
|------|------|
| 菜单 | 右键回波图 → 设置表线深度 |
| 输入 | 默认 2.0 米 |
| 预期 | 回波图上出现一条红色表线 |

**检查点**：
- [ ] 表线正常显示
- [ ] 状态栏更新表线深度值

---

### 第 4 步：启用分析区域

| 操作 | 说明 |
|------|------|
| 工具栏 | 点击分析区域按钮（或右键菜单） |
| 预期 | 表线到底线之间的区域被限定为分析区域 |

**检查点**：
- [ ] 分析区域正确划定（表线到底线）
- [ ] 后续处理仅分析该区域内的数据

---

### 第 5 步：质量检查

| 操作 | 说明 |
|------|------|
| 属性面板 | 点击「🔍 数据质量检查」按钮 |
| 预期 | 弹窗显示 Sv 数据质量和底线质量检查结果 |

**检查点**：
- [ ] 弹窗显示 Sv 范围、数据尺寸、NaN 比例
- [ ] 弹窗显示底线有效 ping 数
- [ ] 显示「质量检查通过」或具体警告信息

---

### 第 6 步：噪声去除

| 操作 | 说明 |
|------|------|
| 属性面板 | 调整噪声参数（ping_num=5, range_sample_num=10, SNR=3.0dB） |
| 菜单 | 处理 → 噪声去除（Ctrl+2） |
| 预期 | 状态栏显示处理进度，完成后回波图更新 |

**检查点**：
- [ ] 噪声去除完成
- [ ] 回波图信噪比提升
- [ ] 原始 Sv 保留不变（Sv_corrected 存储去噪结果）

---

### 第 7 步：底部检测

| 操作 | 说明 |
|------|------|
| 属性面板 | 调整底部阈值（-40 dB） |
| 菜单 | 处理 → 检测底部（Ctrl+3） |
| 预期 | 回波图上出现黄色底线 |

**检查点**：
- [ ] 底线正确显示在回波图上
- [ ] 底线跟随地形起伏

---

### 第 8 步：底线编辑（可选）

| 操作 | 说明 |
|------|------|
| 工具栏 | 鼠标模式切换到「绘制底线」 |
| 操作 | 按住左键在回波图上拖动绘制 |
| 右键 | 完成绘制 / 撤销 (Ctrl+Z) |
| 预期 | 橙色绘制线实时显示，释放后替换底线 |

**检查点**：
- [ ] 绘制过程有实时预览
- [ ] 释放后底线正确更新
- [ ] Ctrl+Z 可撤销编辑

---

### 第 9 步：鱼群检测

| 操作 | 说明 |
|------|------|
| 属性面板 | 调整鱼群阈值（-55 dB） |
| 菜单 | 处理 → 检测鱼群（Ctrl+4） |
| 预期 | 回波图上出现鱼群叠加层 |

**检查点**：
- [ ] 鱼群边界正确显示
- [ ] 统计对话框可查看鱼群数量和面积

---

### 第 10 步：密度估算

| 操作 | 说明 |
|------|------|
| 属性面板 | 设置 TS 值（默认 -30 dB）和平均体重 |
| 菜单 | 处理 → 计算密度（Ctrl+5） |
| 预期 | 密度计算完成，可在统计对话框查看结果 |

**检查点**：
- [ ] 密度估算完成
- [ ] 显示 ind/m² 和 kg/ha 等单位

---

### 第 11 步：网格分析

| 操作 | 说明 |
|------|------|
| 属性面板 | 设置网格参数（垂直间隔 2m，水平间隔 100 pings） |
| 按钮 | 点击「网格分析」 |
| 预期 | 网格分析完成，显示网格单元统计 |

**检查点**：
- [ ] 网格单元包含 cell_id, latitude, longitude, mean_sv, abc 等列
- [ ] 可导出为 CSV/Excel 格式

---

### 第 12 步：数据导出

| 操作 | 说明 |
|------|------|
| 菜单 | 文件 → 导出结果 CSV（Ctrl+E） |
| 选择 | 选择导出内容（Sv/鱼群/密度/网格） |
| 预期 | 导出文件保存到 outputs 目录 |

**检查点**：
- [ ] 导出文件格式正确（CSV/Excel/NetCDF）
- [ ] 导出内容包含必要的列（ping, depth, Sv, 等）

## 三、快捷键参考

| 快捷键 | 功能 |
|--------|------|
| Ctrl+I | 导入 Raw 文件 |
| Ctrl+1 | 计算 Sv |
| Ctrl+2 | 噪声去除 |
| Ctrl+3 | 检测底部 |
| Ctrl+4 | 检测鱼群 |
| Ctrl+5 | 计算密度 |
| Ctrl+E | 导出结果 |
| Ctrl+B | 批量处理 |
| Ctrl+Z | 撤销底线编辑 |
| Ctrl++/- | 缩放 |
| Ctrl+0 | 适应窗口 |
| Escape | 取消绘制 |

## 四、常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 回波图不显示 | 数据未加载 | 重新导入 raw 文件 |
| 底线检测失败 | 阈值设置不当 | 调整底部阈值（-70 ~ -20 dB） |
| 鱼群未检测到 | 阈值过高 | 降低鱼群阈值（如 -60 dB） |
| 导出文件为空 | 未先进行处理 | 先执行计算 Sv 再导出 |
| 批量处理卡死 | 内存不足 | 减小并行度或分批处理 |
