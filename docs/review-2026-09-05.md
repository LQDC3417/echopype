# Echogram 全项目审查与修复记录

审查日期：2026-09-05。目标：面向 Echoview 风格的鱼类声学分析桌面工作台。

结论：项目已具备 RAW 读取、校准、去噪、底线编辑、鱼群识别、积分、SED、项目保存与导出的主要链路。本轮修复了数值计算、坐标基准、项目状态和打包方面的实际错误。现有测试能够证明这些修复的局部行为，不能证明与 Echoview 的科学结果等价。

## 审查范围

| 范围 | 检查重点 |
|---|---|
| `src/core` | 校准调用、合并、掩码、深度与距离、积分和密度、检测、导出、项目保存 |
| `src/gui` | 导入和处理回调、失败保留、参数与结果状态、光标和区域统计、线程取消 |
| `src/viz` | 光标和选区边界、当前显示变量、交互链路 |
| CLI 与安装配置 | 配置验证、跨运行状态、NetCDF 引擎、包目录和图标资源 |
| tests 与本地 RAW | 模拟回归、真实数据链路、格式往返、独立安装包导入 |

项目原有未提交 UI 工作继续保留。此次未提交、推送或发布；没有覆盖原始 RAW。已有界面配色与面板布局不计为本轮新设计成果。

## 距离可靠科研工具还需完成的验证

1. **与参考结果对照。** 用同一 RAW、校准参数、阈值、表底线与 EDSU，逐格对照参考软件的 Sv、积分和目标结果。当前没有提供 Echoview 工程或参考导出，不能宣称等价。
2. **定量重采样守恒。** 现在是线性域点插值，仍不是按采样单元重叠面积的守恒重采样；不同分辨率合并后的积分误差需要单独定量评估。公共距离网格的交集策略也需结合调查范围确认。
3. **真实多文件和多设备验收。** 当前本地只有一个 RAW；多文件失败、去重、通道、坐标映射以构造数据回归为主。尚未证明多种声纳、混合模式和长测线都可稳定运行。
4. **可视交互与性能。** 需要有 OpenGL 的桌面验收：真实声图、缩放平移、底线编辑、较小屏幕布局、大文件内存与长时连续操作。已检查的离屏布局不能替代这些测试。
5. **科学算法边界。** SED 的测角、脉冲判据和波束补偿需要带已知目标的参考数据验证；检测到目标并不等于已证明检测准确率。`core/noise.py` 自定义去噪为遗留路径，当前主要 GUI/CLI 调用 echopype 去噪，不能把遗留实现视为独立验证过的算法。
6. **元数据一致性。** 当前部分按通道固定的校准变量继承首文件；若文件间这些参数变化，应在真实混合调查中验证一致性或明确拒绝不兼容输入。

建议下一阶段以固定验收数据集为主线，先锁定数值一致性与真实多文件稳定性，再扩展工作台功能。本轮不引入前端框架迁移或未经需求确认的大规模重写。
