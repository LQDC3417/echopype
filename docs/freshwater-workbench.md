# 淡水调查工作台与快照重算

## 当前实现（2026-09-27）

工作台通过通道选择器按原始 `channel` ID 切换分析视图；频率仅用于显示。原始多通道 Dataset 保持为共享数据源，各通道独立保存配置、底线、噪声 mask、区域、结果表和过期状态。处理参数变化只更新设置并标记受影响结果待重算；手动启动分析时 Worker 使用配置快照。积分重算前按通道的自动去噪策略处理，再应用人工 mask、分析区域和积分网格。每次成功积分会把实际通道、有效积分参数、RAW SHA-256、软件版本、实现摘要及线/区域/mask 摘要附到该通道的结果记录，并写入 `.ep`。

项目格式为 `.ep` v1.3，按列保存结果表以保留数值精度、纳秒时间、数据类型以及“未计算”和“已计算空表”的区别。旧版本项目仍可读取，其旧 JSON 表历史上发生过的精度损失无法还原。项目打开会重新校验 RAW 并生成 Sv；自动去噪策略会保留，但打开本身不运行去噪。快照 replay 输出记录通道、处理策略和输入校验信息。项目级 provenance 描述保存时快照，与逐次积分运行记录分开。

过期、待核验或部分输入结果可以查看并随项目保存，但不能作为正式分析结果导出。Sv CSV 由选定 Dataset 导出实际存在的深度、距离、GPS 和来源字段；不以采样序号伪造深度或补造 GPS。

自动化验证：`pytest -q` 为 308 passed、39 skipped；`pytest --run-real-data -q -ra` 为 346 passed、1 skipped（因另一个测试数据目录不存在）；Ruff、compileall 和 diff 检查通过。另使用用户提供目录中连续的 10 个现场 RAW（约 1.05 GB）完成导入、接缝、积分、项目保存重开及 replay 一致性验证，逐次运行记录的哈希实测约 0.94 秒，细节见验收记录。尚未取得同一 RAW 的 ESP3/Echoview 基准输出，因此不宣称数值等价；31.29 GiB 全目录未在本阶段整体处理。

## 使用

1. 导入 RAW，填写调查信息，检查数据质量。
2. 确认去噪、表线、底线及分析区域，再执行积分。参数变化后检查待重算提示。
3. 保存 `.ep` 项目。文件菜单可导出已保存快照的复现说明。
4. 选择“按已保存快照重算积分”，指定输出的父目录。软件创建独立目录，不覆盖项目或旧结果。

重算通过桌面工作台的“按已保存快照重算积分”入口启动。输出包含 `Sv.nc`、`integration.csv` 和 `manifest.json`。说明文件记录配置、输入校验和、依赖版本、线段、区域、掩膜摘要及当前计算实现的 SHA256。重算前验证 RAW；输出目录必须不存在。

## 复现边界

这是按当前保存快照重新校准、按保存的去噪状态和当前区域处理并积分，不是历史操作序列回放。特别是先去噪后修改区域的旧操作顺序尚未完整记录。版本被记录但不自动安装或锁定。

重开项目会重新校准；历史积分、鱼群、SED 结果标记为待核验，手工底线和噪声掩膜恢复。分析区域的启用状态会随项目保存。自动去噪不在打开时自动重做。此时再次保存会记录当前处理状态；如需重算原先快照，请先使用原保存文件的重算入口。

旧项目缺少去噪状态或输入校验和时拒绝直接重算，需确认处理状态后保存。重算入口目前只重新生成积分，不重新检测鱼群或单体目标。TS 默认值仍是密度估算假设，应按调查对象设置。

## 2026-09-10：多文件与视图修复

- 多文件公共距离网格覆盖所有文件、所有 ping 的有效范围，按时间排序；来源随 ping 保存为 `source_file`，交界显示白色虚线，悬停查看前后文件和时间。断档按典型间隔的 5 倍识别并在合并状态中提示，横轴仍为连续 ping，不填补虚构数据。
- 相同时间且 Sv 一致时去重；冲突 Sv、缺失距离、声道或校准参数不兼容时报错。并集网格的缺测位置保持 NaN，显示为灰色。部分 ping 尾部缺测不会再导致相同采样网格多出一格。
- 滚轮每标准格约 5%，高精度增量按比例处理；最小倍率为全图 100%，绘图区首尾、上下贴边。平移、导航和窗口尺寸变化受同一边界约束。首次显示不会因 Qt 的无效旧尺寸异常放大。
- 色标是右侧独立窄栏，刻度和无数据图示使用浅色文字；声图及接缝限制在绘图区。中文优先使用系统雅黑字体，右键操作复用 SVG 图标，避免依赖缺字的 emoji。
- 旧项目掩膜尺寸与新拼接网格不同会拒绝套用并保留当前项目；需重新导入检查，原项目文件不改写。
- 积分对照发现短 ping 最后有效样本的厚度被 NaN 尾部吞掉；现沿用前一个有效采样厚度，与完整 ping 末点规则一致。距离坐标保持双精度，减少采样厚度量化误差。

验证包含 Windows 原生 OpenGL 窗口的全图、放大、连续缩小，以及真实 RAW 分段后逆序拼回。真实输入只有一个 178 MB RAW，不能代替用户异常文件组合的验收。该分段验证中 Sv 与原数据 float32 值逐点相等、积分样本计数一致，ABC 最大绝对差约 `1.32e-9`；不同采样网格仍采用线性声强域点插值，不宣称积分守恒。

最终回归：包含真实数据的测试 331 通过、1 跳过，Ruff 检查通过。临时检查截图已查看并清理。
